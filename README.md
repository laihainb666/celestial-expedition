# 苍穹远征：星陨传说 (Celestial Expedition: Starfall Legend) v3.0.0

超大型纯 Python 文字冒险 RPG，零第三方依赖，玩法丰富。

## 运行

```bash
python3 celestial_expedition.py          # 分模块版（主程序 + 数据模块）
python3 celestial_expedition_onefile.py  # 单文件版（约 2.8MB，可直接分发）
python3 ai_play.py                       # AI 自动游玩脚本
```

## 模组系统（模块化架构）

在 `mods/` 目录放置 `.py` 模组文件，定义 `MOD_NAME` / `MOD_ITEMS` / `MOD_MONSTERS` / `MOD_EVENTS` 即可扩展游戏内容：
- 游戏启动时自动扫描加载，示例见 `mods/example_mod.py`
- 示例模组加载后新增 7 项内容（新装备/新怪物/新事件）
- 模组内容与内置内容无冲突（按 id / 名字去重注册）

## AI 自动游玩（ai_play.py）

```bash
python3 ai_play.py --rounds 20          # 自动游玩 20 回合
python3 ai_play.py --load ai_test_save.json   # 读取存档续玩
python3 ai_play.py --save my_save.json  # 指定存档路径
python3 ai_play.py --quiet              # 安静模式（只输出关键节点）
```

AI 策略：自动战斗（技能/普攻/用药/逃跑判断）、自动买药补血、自动购买装备、推进区域、每 10 回合自动存档。

## 内存要求说明

进程常驻内存（RSS）实测：分模块版约 **23 MB**，单文件版约 **18 MB**，远超 **800 KB** 目标。
来源：Python 解释器基础占用 + 大型数据表（6737 装备/220 怪物/600 事件）+ 150x150 区域网格地图。
启动与退出时游戏会自行打印当前进程内存占用，可直接验证。

## 快捷游玩提示

- 初始金币 100，先探索 + 战斗升到 3~5 级，再去商店买装备
- 每个区域地图传送需要推进到该区域（击败前区域 BOSS 或达到等级）
- 星之神殿（区域 8）是最终 BOSS 区，击败星陨之神通关
- 战斗中防御可叠加护盾，BOSS 战记得用药
- 想快速体验后期内容？设置菜单开「一击必杀」+「无敌模式」即可无双刷怪
- 想体验模组？把 mods/example_mod.py 放到 mods/ 目录后启动游戏
- 想挂机？直接 `python3 ai_play.py --rounds 50`
